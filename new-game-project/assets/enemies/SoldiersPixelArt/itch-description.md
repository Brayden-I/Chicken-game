## What's inside

**v0.9 is a big one.** The pack went from one soldier walking one direction to three characters moving and fighting in eight.

### 🪖 Three characters

**Vanguard** — horned helm, goggles, SMG · 64×64
**Armored Soldier** — heavy plate · 64×64
**Rifle Soldier** — the original, now fully animated · 64×64

### 🎞️ Three animations, eight directions

Every character walks, stands and fires in all eight directions — N, NE, E, SE, S, SW, W, NW.

- **Idle** — 4 frames, subtle breathing, loops
- **Walk** — 8 frames, alternating footfalls, loops
- **Fire** — 4 frames, muzzle flash and recoil

That's **72 animations** and **384 individual frames**.

### 🌿 Grass & dirt tileset (32×32)

- **16 tiles** on a single 128×128 sheet
- Seamless grass and dirt base tiles — verified wrapping, no visible seams
- Full **3×3 transition block** plus four inner corners, so dirt patches and paths drop into grass with proper organic edges
- Sample terrain image included for reference

### 📦 Every animation ships twice

- **`.png` sprite sheet** — one row, fixed cell size, ready to slice
- **`.gif` preview** — so you can see it move before you import it

## Built to import cleanly

I got tired of packs that look fine and then fight you in the engine, so:

- **One grid for everything.** Every character slices on 64×64. Set your import once and it works across the whole pack.
- **No wobble between states.** Within each character, the ground line sits on the same row in idle, walk *and* fire — so switching animation mid-game doesn't make the sprite hop.
- **Planted feet.** A foot bearing weight never drifts. No skating.
- **Clean alpha.** Zero semi-transparent pixels — stays crisp with Point filtering.
- **Nothing touches the cell edge**, so no bleeding between frames.

Full import settings for Unity are in the README.
